## Project Description
A Python application that allows users to merge multiple PDF files into a single PDF and split specific pages from a PDF document.

## Features
- Merge Multiple PDF Files
- Split PDF Pages
- Simple and Easy to Use

## Technologies Used
- Python
- PyPDF2
- VS Code

## How to Run
1. Install PyPDF2:
   pip install PyPDF2

2. Run the program:
   python pdf_merger_splitter.py
